💡 프롬프트 혼선 방지 안내

  • 수업 자료와 이미지 프롬프트가 독립된 탭으로 완벽히 분리되어 있어, 프롬프트가 서로 섞이거나 꼬이지 않습니다.
  • 이미지 프롬프트는 추상적인 문구 대신 구체적인 시각 행동(Visual Translation)으로 치환되어 배경 외계어/한글 깨짐 현상이 원천 차단됩니다.
  • 상단 AI 모델 칩(Gemini, ChatGPT, Midjourney 등)을 누르면 해당 도구의 전용 문법으로 즉시 전환됩니다.
